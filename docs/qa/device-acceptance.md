# Device Acceptance

Device acceptance is separate from unit testing. It proves the production booth can operate the real hardware and vendor software under pressure.

## Required Before v1

- vMix: Check API, Preview title, Take live, Clear.
- OBS Studio: Connect, Preview text, Live text, Clear.
- EasyWorship: Export slide, import through watch folder, confirm no admin elevation.
- HDMI: Detect display, verify safe area, rehearse disconnect and reconnect.

## Optional But Recommended

- ProPresenter: API health and playlist cue.
- NDI: Discovery and alpha-channel lower third.
- OSC and Companion: Preview, live, clear, black, and freeze mappings.

## Evidence

Each rehearsal should capture:

- Date, operator, and service profile.
- Software versions.
- Device names and addresses.
- Pass/fail for every required step.
- Screenshot or phone photo for output proof.
- Any recovery action needed.

No acceptance result should mark a device as production-ready until the real device is tested in the church booth.
