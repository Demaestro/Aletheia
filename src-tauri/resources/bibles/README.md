# Bundled Bible Resources

Bundled full-canon translations must be legally distributable for offline use.

- `kjv-full.json`: King James Version, public domain.
- `bbe-full.json`: Bible in Basic English, public domain.
- `web-full.json`: World English Bible, public domain. Source: https://github.com/TehShrike/world-english-bible

Do not commit full NKJV, MSG, NLT, ESV, NIV, or other publisher-controlled
translations unless the project has a written redistribution license. Aletheia
supports importing licensed JSON files through the Bible/import workflow.
